## 🧠 What's Inside

This portfolio is organized around the core areas of prompt engineering I'm exploring:

- **Prompt Patterns** — reusable structures for common tasks (summarization, extraction, classification, role-based prompting)
- **System Prompts** — designed for specific use cases like customer service, HR, and content generation
- **Chain-of-Thought Experiments** — exploring how reasoning steps affect output quality
- **Real-World Applications** — prompts I've used in actual workflows and tools
